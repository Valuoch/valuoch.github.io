The bug that looked like success

While testing offline capture and sync, I found field records that were silently held on workers' phones: the app showed them as submitted, but the server had rejected them. I traced the issue from the device through the API to the database and reported it with evidence. It was the kind of defect that only end-to-end tests on real devices reveal.
